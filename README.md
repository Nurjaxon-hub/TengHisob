# TengHisob

Do‘kon egalari va xaridorlar uchun hisob-kitob ilovasi.

## Imkoniyatlar

- Savdo va tushumlarni qayd etish
- Xarajatlarni hisobga olish
- Mahsulotlar va ombor qoldig‘ini yuritish
- Xaridorlar qarzini qayd etish
- Xaridor qarzni tasdiqlashi yoki e’tiroz bildirishi
- Qisman qarz to‘lovlarini qayd etish
- Bildirishnomalar
- Hisobotlar va CSV faylga chiqarish
- O‘zbek va rus tillari

## Texnologiyalar

- HTML, CSS va JavaScript
- Supabase
- Capacitor
- Android

## APK yaratish

GitHub sahifasida Actions bo‘limini oching.

`Build TengHisob APK` jarayonini tanlang va `Run workflow` tugmasini bosing.

Jarayon muvaffaqiyatli tugagach, `TengHisob-APK` faylini Artifacts bo‘limidan yuklab oling.
